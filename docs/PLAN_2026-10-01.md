# MilkyBody 全体デバッグ＆機能追加 計画書（2026-10-01）

## 0. 前提・制約

- この作業環境には UE 5.7 が無いので、**ビルドと実機確認はできない**。修正はすべて手元でビルドして動作確認してもらう必要がある。
- そのため、まだ使っていないエンジン API はなるべく増やさない。既存コードで使っている API を中心に直す。
- 対象は `Source/` と `Shaders/` 全体。全ファイルを読んでレビュー済み。

## 1. 見つかったバグ

### A. 重大

| # | 内容 | 場所 | 対策 |
|---|------|------|------|
| A1 | **Damping ≥ 0.6 でバネが発散する**。頂点が無限遠や NaN になり、メッシュが壊れる（数値シミュで確認済み。UI では 0〜1 を入力できる） | `MilkyBodyDeformerInstance.cpp` EnqueueWork | 240Hz の固定サブステップにする。Damping 0.1 での手触り（オーバーシュート 1.44）は変わらない |
| A2 | **フレームレートに依存する**。EnqueueWork が呼ばれるたびに dt=1/60 で 1 ステップ進むため、144fps だと 2.4 倍速、30fps だと半速になる。揉み・こね・引っ張り追従も同じ | 同上 | World の DeltaSeconds を使う。1 フレームに 1 回だけ進めるガードも付ける |
| A3 | `DeformerAsset` に `UPROPERTY()` が無いので、GC がこの参照を追跡しない | `MilkyBodyDeformerInstance.h` | `UPROPERTY()` を付ける |
| A4 | `ApplyPuni` 系の **DurationSeconds が使われていない**（ドキュメントの説明と一致しない）。凹みのピークも PushDepth の約 14% しかない | `ApplyPushImpulse` | **要相談**（Q2） |
| A5 | コンポーネントのスケールが 1 でないと、半径と深さがずれる。半径はワールド値をローカル距離と比較しており、impulse は NoScale で変換している | Instance 全般 | 半径はスケールで割り、impulse はスケール込みで変換する |

### B. 中

| # | 内容 | 対策 |
|---|------|------|
| B1 | シェーダー: スロットが重なると、前のスロットで動いた位置を使って次のスロットの距離を評価している。複数の指が重なったときに、処理順で歪みが変わる | 距離は変形前の位置で評価する |
| B2 | `SectionVertexOffset` にセクション頂点数の累積値を使っている。正しくは `BaseVertexIndex`（取得済みなのに未使用）。普通のメッシュでは同じ値になるが、保証はない | `BaseVertexIndex` を使う |
| B3 | EnqueueWork の中で `DrawDebugSphere` を呼んでいる。EnqueueWork はワーカースレッドから呼ばれる可能性がある（`SendRenderDynamicData_Concurrent`）ので、デバッグ描画 ON のときだけクラッシュする潜在要因になる | 描画をゲームスレッドに回す |
| B4 | パッケージ版では、ポリゴントレースと BoneSpherePuni の表面スナップが使う CPU スキニングに、メッシュの「Allow CPU Access」が必要。無いと無反応になるか、クラッシュする恐れがある | 事前にチェックし、警告ログを 1 回だけ出す |
| B5 | `SetHoldPuniUnderCursor` でカーソルがメッシュの外に出ると、OutMeshComp が null になる。すると BP 側で Release できず、**凹みが残り続ける** | **要相談**（Q3） |
| B6 | Physics Asset が無いときのトレースのフォールバックが、AABB や外接球の入口を当たり点にしている。そのため凹みの中心が空中に来たり、キャラの近くを空振りしただけで凹んだりする | **要相談**（Q4） |

### C. 軽微・整理

- C1: `BoneSpherePuniComponent.cpp` の `ComputeTargetHits` が未使用のデッドコード（同じロジックが ApplyNow に重複している）
- C2: QUICK_START / TESTING_GUIDE / IMPLEMENTATION_COMPLETE が旧 PBD 版の内容のまま（VertexIndexStart、SolverIterations など、今は存在しないパラメータが載っている）。現行の内容に書き直す
- C3: `.gitignore` が無い。LICENSE は削除済みなのに、ドキュメントには MIT と書いてある
- C4: コメントの数値ずれ（コメントは「最大 3 点」、実装の clamp は 4）

## 2. 機能追加の候補（選んでもらう）

| ID | 内容 | 規模 |
|----|------|------|
| F1 | 指ごとのフェード。今は指が離れた瞬間に凹みがパッと消えるので、指ごとにバネで戻す | 小〜中 |
| F2 | 食い込み連動。指が深く食い込むほど凹みも深くする（今は一律 ImpulseDepth） | 小 |
| F3 | 同時インタラクション。今は 1 メッシュにつき 1 モードの排他で、クリックホールド中に指が触れるとどちらかが消える。これを併用できるようにする | 中 |
| F4 | 変形マスク。頂点カラーかボーン指定で、凹んでよい部位を限定する（顔や骨ばった部位を除外） | 中 |
| F5 | BP ユーティリティ。現在の押し込み量の取得、全解除（ReleaseAll）、「触れているか」の判定 | 小 |
| F6 | コンポーネント単位のパラメータ上書き。同じアセットのまま、キャラごとに硬さを変えられるようにする | 中 |
| F7 | モーフターゲット対応。今はデフォーマを適用している間、モーフが無効になる | 中〜大（API 未確認のリスクあり） |
| F8 | 慣性揺れ（ジグル）。キャラの動きで揺れる、本来の soft body | 大 |
| F9 | コンソール変数と stat（`milkybody.Enable`、`milkybody.DebugDraw`、GPU 時間） | 小 |

- トレース時のワールド全アクター走査（`GetAllActorsOfClass`）: 性能改善の候補。後回し。
- バネを陰的オイラーで安定化する案: 数値減衰が強く、プニプニ感が消えるので没。サブステップ方式を採用する。

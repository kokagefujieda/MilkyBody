## 3.5 決定事項（2026-10-01 回答）

- 機能追加: F1+F2、F3、F4、F5+F9 をやる。F6・F7・F8 は今回やらない。
- A4 ApplyPuni: 「押す→ DurationSeconds の間保持→バネで戻る」にする。DurationSeconds=0 のときは旧来のキックにする。
- B5 凹みが残る問題: 自動解除（`HoldAutoReleaseSeconds`、既定 0.15 秒）と ReleaseAll 関数の両方を入れる。
- B6 トレースのフォールバック: ポリゴン判定に置き換える。

- F2 食い込み連動: 既定 ON。ImpulseDepth は深さの上限という意味になる。

## 3.6 設計

- **シミュレーションの移動**: シミュは EnqueueWork から `FTickableGameObject::Tick`（ゲームスレッド）に移す。
  - 実際の dt を使い、240Hz の固定サブステップで回す。
  - デバッグ描画も Tick で行う。
  - 動いている間は `MarkRenderDynamicDataDirty` を呼ぶ。アニメーションしていない静止メッシュでも、凹みのバネが動くようにするため。
- **接触モデル (F3)**: どの操作も「接触」として扱い、接触ごとに専用のバネを持つ。全部を加算で重ねる。
  - Hold ×1、Impulse ×最大 4、Kneading ×最大 4、Momi ×最大 4、External ×残り。
  - スロット上限は 16 から 32 に増やす。
  - External は (送り元オブジェクト, 接触 ID) で識別する。これで両手（コンポーネント 2 つ）が同じ体を揉んでも、上書きし合わない。
  - 更新が来なかった External 接触は、自動でフェードする (F1)。
- **ボーンマスクの GPU 計算**: 各ボーンの「柔らかさ」を、行列 row0.w だけを持つダミーのボーン行列バッファにしてシェーダーに渡す。
  - これをエンジンのウェイトブレンド関数（Limited と Unlimited の両方）にそのまま通すと、Σ w·softness が得られる。
  - ウェイトのデコードを自前で書かずに済む。
- **表面スナップの法線の向き**: 三角形の巻き方向は、ref pose の頂点法線 (TangentZ) と比べて、メッシュと LOD ごとに 1 回だけ判定する。
  - 食い込みの深さ = R − d（指の中心が外側にあるとき）、R + d（内側にあるとき）。

## 4. 保留・没案メモ

- F6（コンポーネント単位のパラメータ上書き）、F7（モーフターゲット）、F8（ジグル）: 今回はやらない。
- 表面スナップ: 指の中心が表面より R 以上深く潜ると接触が外れる。探索半径を広げる案は後回し。
- GPU stat: 5.6 以降で GPU プロファイラが変わったので、`RDG_GPU_STAT_SCOPE` は使わない。`RDG_EVENT_SCOPE` だけにしておく（ProfileGPU や Insights で見られる）。
- LICENSE ファイルは削除済みなのに、ドキュメントには MIT と書いてある。法的な判断なので、ユーザーに確認するまで触らない。

- エディタビューポートでのプレビュー: 非ゲームワールドでは過去にクラッシュ回避のためフォールバックにしているので、今回は触らない。
- `FAssetTypeActions_Base` から `UAssetDefinition` への移行: 動いているので保留。
- トレース時のワールド全アクター走査（`GetAllActorsOfClass`）: 性能改善の候補。後回し。
- バネを陰的オイラーで安定化する案: 数値減衰が強く、プニプニ感が消えるので没。サブステップ方式を採用する。

### API の変化（互換性）

- BP ノードのシグネチャは変えていない（関数の追加のみ）。
- 挙動の変化:
  - ApplyPuni が保持型になった。
  - Hold / Kneading / Momi / 指が互いに打ち消さず、重なるようになった。
  - `ReleaseHoldPuni(0)` が解除するのはホールドだけになった（全解除は `ReleaseAllPuni`）。
- C++: `BeginExternalMultiHold` / `EndExternalMultiHold` は互換用ラッパーとして残した。新しいコードは `UpdateExternalContacts(Source, Ids, ...)` を使う。

### 後で考えること

- `PenetrationDepthScale` の既定値（1.0）は、見た目で調整が必要かもしれない。見た目の凹み = 深さ × GeometryDepthScale (0.3) なので、肌を指に追従させるなら 3 前後になる。
- 指の Tick に `TickInterval` を付けると、更新が無いフレームにフェードが始まってしまう。必要なら猶予フレームを足す。
